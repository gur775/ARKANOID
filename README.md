# Игра Арканоид на библиотеке SFML 3.0
## Условия
Вверху поля множество прямоугольных блоков. Внизу горизонтально перемещается каретка. По полю летает «мяч», отражаясь от стен, блоков и каретки. Если мяч попадает вниз (мимо каретки) уменьшается число очков игрока. 
### Блоки бывают разных типов:
1) Неразрушаемые. От них мяч просто отскакивает.
2) Блоки могут быть со спрятанными бонусами: при попадании вертикально вниз падает бонус
3) Блоки, увеличивающие скорость шарика при столкновении
4) Блоки имеют уровень здоровья = число попаданий, чтобы блок исчез. За каждое попадание +1 очко игроку, -1 очко здоровья блоку.
### Виды бонусов: , меняют скорость шарика, .
1) Одноразовое дно для шарика – можно один раз пропустить, дно сработает как каретка, и исчезнет.
2) Уменьшают размер каретки на 15 секунд.
3) Вызывают прилипание шарика к каретке до нажатия пробела. Каретка двигается вместе с прилипшим шариком.
4) Появляется второй шарик, способный оттолкнуться и от первого, и от блоков/стенок.
### Управление игровым процессом
В начале игры игроку даются три жизни. При пропускании мяча количество жизней уменьшается на единица за каждый пропуск. Если количество жизней становится равным нулю, то игра закончилась. Для повторного запуска нужно нажать пробел.
Если все уничтожаемые блоки уничтожены, то игрок выиграл.

#### Игра управляется с помощью клавиш:
##### 1) "Стрелка влево/вправо" - для передвижения каретки влево/вправо.
##### 2) Для перезапуска игры по случаю победы/поражения необходимо нажать пробел. Эта же клавиша нажимается в случае, если активирован бонус с прилипанием шарика.

### Запуск игры
Для запуска нужно открыть файл ```.exe```.
